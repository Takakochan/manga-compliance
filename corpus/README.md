Legal and guideline texts the citations come from, one Markdown file per document, in a folder per country. Headings follow the document's own structure (sections, articles, categories), so each search chunk knows where it sits.

Rules for this folder:

- Copy the official text; do not paraphrase. Citations are checked character by character.
- Put the source URL and the date you copied it at the top of each file.
- The USK criteria are for games. Say "by analogy" wherever we use them.
